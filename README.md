# 🐶 大型電子寵物互動樂園 · Virtual Dog Pet 🐾

一個以邊境牧羊犬為主角的療癒系大型電子寵物互動網頁遊戲！

## ✨ 特色亮點

- 🐕 **高畫質動態寵物視訊**：精選邊境牧羊犬專屬情境影片，涵蓋餵食、洗澡、看醫生、多樣戶外探險等！
- 🚀 **環遊世界與太空探險**：
  - 🎨 巴黎羅浮宮欣賞名畫《蒙娜麗莎》
  - 🔴 登陸火星漫步探索
  - 🚀 國際太空站與浩瀚宇宙星空漫步
  - 🏰 夢幻迪士尼城堡、萬里長城、台北 101、日本櫻花神社、浪漫義大利水都等
- 📊 **5 大健康狀態儀表板**：即時追蹤健康、飽足感、水分、衛生與親密度數值，並隨數值連動心情變化。
- 🎵 **Web Audio 療癒合成音效**：內建按鈕互動清脆音階，可隨時一鍵開關音效。
- 💤 **多樣化待機姿態**：動作結束後智慧輪播「精神飽滿站姿照片」、「小窩熟睡影片」與「客廳趴地休息影片」，播完即優雅定格。
- 🔒 **動作防斷流保護**：動作期間自動鎖定按鈕，保證每部影片流暢完整播放至最後一格。

## 🎮 操作方式

直接開啟 `index.html` 即可在任何現代瀏覽器中進行遊戲！
點擊右側 9 大紫色互動按鈕，即可與專屬邊境牧羊犬進行即時互動。
